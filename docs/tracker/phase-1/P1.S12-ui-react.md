## 3. Kiến thức quan trọng / Keyword cần nắm

Danh sách khái niệm PHẢI hiểu được (không chỉ copy-paste code) trước khi coi buổi này là xong:

- **`useMutation`** — dùng cho POST `/ask` vì đây là một *action* (gửi câu hỏi, có side-effect ở backend), không phải một *query* đọc dữ liệu định kỳ như `useQuery`. `useMutation` không tự fetch khi mount, chỉ chạy khi gọi `mutate()`.
- **Loading/error/success state pattern** — `useMutation` trả về `isPending`, `isError`, `error`, `data`, `isSuccess`; UI render theo state này (spinner khi `isPending`, message khi `isError`, bảng kết quả khi có `data`) — không tự quản state thủ công bằng `useState` chồng chéo.
- **Dynamic table rendering** — mỗi câu hỏi trả về cột (columns) khác nhau tuỳ query SQL sinh ra, nên bảng kết quả phải render `<thead>`/`<tbody>` động từ `columns` + `rows` trả về từ API, không hardcode tên cột.
- **CORS** — nhắc lại từ `P1.S11`: FastAPI backend phải bật `CORSMiddleware` cho phép origin của Vite dev server (mặc định `http://localhost:5173`), nếu không request từ UI sẽ bị browser block.

## 4. Các bước nhỏ (step-by-step)

1. **Scaffold project Vite + React + TS**
   - `npm create vite@latest ui -- --template react-ts`
   - `cd ui && npm install`
   - Kỳ vọng: `npm run dev` chạy, mở `http://localhost:5173` thấy trang Vite mặc định
2. **Cài TanStack Query + HTTP client**
   - `npm install @tanstack/react-query axios`
   - Wrap `<App />` bằng `QueryClientProvider` (tạo `QueryClient` mới) trong `main.tsx`
   - Kỳ vọng: app vẫn chạy bình thường, không lỗi console
3. **Tạo component `AskForm`**
   - Input text cho câu hỏi + nút submit, dùng `useState` giữ giá trị input
   - Kỳ vọng: gõ được, click submit gọi hàm handler (chưa cần gọi API ngay)
4. **Gọi POST `/ask` bằng `useMutation`**
   - `const { mutate, data, isPending, isError, error } = useMutation({ mutationFn: (question: string) => axios.post('http://localhost:8000/ask', { question }).then(r => r.data) })`
   - Submit form → gọi `mutate(question)`
   - ⚠️ Lỗi thường gặp: quên bật CORS ở FastAPI (`P1.S11`) → request bị block, console báo CORS error dù backend chạy đúng
5. **Hiển thị SQL sinh ra**
   - Từ `data.sql` (tuỳ shape response backend `P1.S11` trả về), render trong `<pre><code>` để giữ format
   - Kỳ vọng: sau khi submit thành công, thấy đúng câu SQL backend sinh ra
6. **Render bảng kết quả dynamic**
   - Từ `data.columns` (array tên cột) + `data.rows` (array of array/object) → `<table>` với `<thead>` map `columns`, `<tbody>` map `rows`
   - Kỳ vọng: mỗi câu hỏi khác nhau ra cột khác nhau, bảng vẫn render đúng không cần sửa code
7. **Xử lý loading spinner + error message**
   - `isPending` → hiện spinner/text "Đang xử lý..."
   - `isError` → hiện `error.message` (hoặc message từ response lỗi backend) màu đỏ
   - Kỳ vọng: tắt backend thử submit → thấy error message rõ ràng, không crash trắng trang

## 5. Output mong muốn

- [ ] `npm run dev` chạy UI tại `http://localhost:5173` không lỗi
- [ ] Nhập câu hỏi tiếng tự nhiên trên UI → thấy SQL sinh ra (code block) + bảng kết quả trả về từ FastAPI backend thật (`P1.S11`), không phải mock data
