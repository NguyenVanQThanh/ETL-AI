## 3. Kiến thức quan trọng / Keyword cần nắm

Danh sách khái niệm PHẢI hiểu được (không chỉ copy-paste code) trước khi coi buổi này là xong:

- **REST endpoint design** — `POST /ask` nhận `question` (text), trả `{ sql, columns, rows, error }`. Dùng POST (không GET) vì input là "câu hỏi tự do", có thể dài, và về semantic đây là hành động xử lý (không idempotent-lookup đơn giản).
- **Pydantic request/response model** — khai báo `class AskRequest(BaseModel)` và `class AskResponse(BaseModel)` với type hint; FastAPI tự parse JSON body, validate type, và tự sinh schema OpenAPI — sai type/thiếu field trả lỗi 422 tự động, không cần code validate tay.
- **CORS (Cross-Origin Resource Sharing)** — browser mặc định chặn JS ở origin A (vd React UI ở port dev-server) gọi fetch tới origin B (API port khác) trừ khi server B khai báo header `Access-Control-Allow-Origin`. Không có `CORSMiddleware` → UI gọi `/ask` sẽ bị browser block, dù `curl`/Postman gọi vẫn được (vì CORS chỉ áp browser).
- **Health check endpoint** — `GET /health` trả nhanh `{"status": "ok"}`, không chạm DB/LLM. Dùng để orchestration (Docker healthcheck, load balancer, uptime monitor) biết service còn sống, tách biệt khỏi lỗi logic nghiệp vụ ở `/ask`.

## 4. Các bước nhỏ (step-by-step)

1. **Tạo Pydantic model cho request/response**
   - `AskRequest(BaseModel)`: `question: str`
   - `AskResponse(BaseModel)`: `sql: str | None`, `columns: list[str] | None`, `rows: list[dict] | None`, `error: str | None`
   - Kỳ vọng: import 2 class không lỗi, `AskResponse(sql=None, columns=None, rows=None, error="x")` khởi tạo được.
2. **Viết `POST /ask`**
   - Nhận `AskRequest`, gọi hàm agent A3 (đã có guardrails từ P1.S10), map kết quả agent → `AskResponse`, bắt exception → trả về `error` field (không để lộ raw traceback).
   - Kỳ vọng: gọi `/ask` với question hợp lệ → trả JSON đúng 4 field.
   - ⚠️ Lỗi thường gặp: quên `response_model=AskResponse` → Swagger UI không hiện schema response đúng.
3. **Viết `GET /health`**
   - Trả cứng `{"status": "ok"}`, không gọi DB/LLM.
   - Kỳ vọng: gọi `/health` → 200, body `{"status":"ok"}`.
4. **Thêm `CORSMiddleware`**
   - `app.add_middleware(CORSMiddleware, allow_origins=["http://localhost:5173"], allow_methods=["*"], allow_headers=["*"])` (port 5173 = Vite default, dùng cho UI ở P1.S12).
   - Kỳ vọng: request từ origin dev-server UI không bị browser CORS-block (test thật ở P1.S12 khi có UI).
   - ⚠️ Lỗi thường gặp: để `allow_origins=["*"]` trong lúc `allow_credentials=True` — spec CORS không cho phép, browser sẽ reject.
5. **Chạy uvicorn + test qua `/docs`**
   - `uvicorn main:app --reload`
   - Mở Swagger UI (path `/docs`, tự sinh từ Pydantic model) trên host local đang chạy uvicorn → "Try it out" trên `POST /ask` và `GET /health`.
   - Kỳ vọng: cả 2 endpoint trả đúng response, `/docs` hiện đúng schema `AskRequest`/`AskResponse`.
